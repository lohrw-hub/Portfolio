# Wesley H. Lohr — Neurotechnology Engineering Portfolio (v4)

Static website suitable for GitHub Pages. Upload the **contents of this directory** to the repository root. The homepage is `index.html`.

## Changes in v4
- Homepage uses an original rendering of `Brain.stl`, not a screenshot.
- Removed the second CTA and metrics stripe (as annotated in review screenshot).
- New human-model viewer with independently selectable head, skull, CSF and brain layers.
- New rendered model cards in fixtures.
- The source SolidWorks files, original STLs, PCB file, and dissertation PDF are **not** in this public package.
- No intentional native-file downloads anywhere in the interface.

## Privacy caveat
A browser renders all its visual assets on the visitor's device. The raster images, visible figure images, PCB vector rendering, and decimated mesh data are therefore technically recoverable; this is a view-only site, **not** a copy-protected site. Use screened/redacted previews if any design is confidential.

## Contents
HTML page files at the root, CSS/JS and images under `assets/`. This site has no backend, build dependencies, or third-party runtime scripts.
